
# PortPulseAI ⚓

PortPulseAI is a simple project that helps analyse port operations and explore possible recovery plans.

### Features
- Risk Dashboard
- Container Journey
- Bottleneck Analysis
- Recovery Simulation
- Recovery Recommendations
- Port-Call Coordination
- Exception Management

### Tools Used
Python, Streamlit, Pandas and Plotly.

### Run the Project
```bash
pip install -r requirements.txt
streamlit run app.py
```

Note: Some features use sample data and simulated scenarios.
